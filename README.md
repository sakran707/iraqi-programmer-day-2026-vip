# يوم المبرمج العراقي 2026 — نظام تسجيل الشخصيات VIP

نظام داخلي (غير عام) لأعضاء مجلس نقابة المبرمجين العراقيين واللجان المحددة،
لتسجيل الشخصيات VIP المدعوّة لحضور فعالية **يوم المبرمج العراقي 2026** (9–10
تشرين الأول 2026).

مبني على نفس نمط مشروع [`sakran707/election-check`](https://github.com/sakran707/election-check)
(صفحات ثابتة HTML/CSS/JS، بدون إطار عمل، RTL بالكامل، منشور عبر GitHub Pages)،
مع إضافة قاعدة بيانات مركزية Online (Google Sheets عبر Google Apps Script)
بدلاً من البيانات المضمّنة، لأن هذا النظام يحتاج للكتابة (تسجيل) وليس فقط
القراءة.

## الصفحات

| الصفحة | الغرض | من يستخدمها |
|---|---|---|
| `index.html` | استمارة تسجيل الشخصيات VIP | أعضاء المجلس/اللجان (رابط غير معلن) |
| `verify.html` | التحقق من رمز VIP عبر مسح QR أو إدخاله يدوياً | المنظمون عند باب القاعة |
| `admin.html` | لوحة إدارة: إحصائيات، بحث، تعديل، حذف، تسجيل حضور | الإدارة فقط (بكلمة مرور) |

لا يوجد أي "قائمة عامة" — الصفحتان `index.html` و`admin.html` غير معلنتين
(`robots.txt` يمنع فهرستهما)، ولوحة الإدارة محمية بكلمة مرور تُتحقق منها من
طرف الخادم.

## 1) إنشاء قاعدة البيانات (Google Sheet + Apps Script)

هذه الخطوات تُنفَّذ مرة واحدة فقط، من حساب Google الخاص بك (غير مرتبطة بأي
مفتاح أو سر داخل المستودع):

1. افتح [sheets.google.com](https://sheets.google.com) وأنشئ **جدول بيانات
   فارغ** جديد، سمّه مثلاً "VIP يوم المبرمج 2026".
2. من القائمة: **الإضافات (Extensions) → Apps Script**.
3. احذف أي كود موجود في `Code.gs` والصق بدلاً منه محتوى الملف
   [`google-apps-script/Code.gs`](google-apps-script/Code.gs) من هذا المستودع بالكامل.
4. من القائمة اليسرى في محرر Apps Script: **إعدادات المشروع (Project Settings)
   ⚙️ → Script Properties → Add script property**:
   - **Property**: `ADMIN_PASSWORD`
   - **Value**: كلمة مرور قوية من اختيارك لدخول لوحة الإدارة (لا تكتبها في أي
     مكان داخل المستودع).
5. من الأعلى: **Deploy → New deployment**.
   - اضغط أيقونة الترس بجانب "Select type" واختر **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy**، وامنح الأذونات المطلوبة (Authorize access) بحساب Google
     الخاص بك.
6. انسخ الرابط الناتج الذي ينتهي بـ `/exec` — هذا هو رابط تطبيق الويب.

> هذا الرابط ليس سرّاً (هو نقطة نهاية عامة كأي API)، لكنه لا يسمح بقراءة أي
> بيانات إدارية بدون كلمة المرور التي أدخلتها في الخطوة 4.

## 2) ربط الواجهة بالخادم

افتح `assets/config.js` في المستودع وضع رابط `/exec` مكان القيمة المؤقتة:

```js
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

ثم احفظ وادفع (commit + push) — سيُعاد نشر الموقع تلقائياً عبر GitHub Pages.

## 3) تفعيل GitHub Pages (مرة واحدة)

من إعدادات المستودع على GitHub:
**Settings → Pages → Build and deployment → Source: Deploy from a branch**
اختر Branch: `main` والمجلد `/ (root)` ثم **Save**.

بعد دقيقة أو دقيقتين سيصبح الموقع متاحاً على:
`https://sakran707.github.io/iraqi-programmer-day-2026-vip/`

## هيكل البيانات (Google Sheet — ورقة `VIPs`)

```
vip_id | vip_code | full_name | workplace | position | contact_method |
status | priority | entered_by_name | entered_by_position | created_at |
updated_at | attendance_time
```

تُنشأ هذه الورقة والعناوين تلقائياً عند أول استخدام للنظام (لا حاجة لإعدادها
يدوياً). إذا كان الجدول موجوداً مسبقاً من نسخة أقدم من الكود، يكمّل الخادم
تلقائياً أي عمود جديد (مثل `priority`) دون المساس بالبيانات الموجودة.

## أولوية الحضور

بسبب محدودية المقاعد المخصصة للشخصيات VIP، إذا سجّل العضو أكثر من شخصية
بنفس الجلسة، تظهر له عند الضغط على "إنهاء" قائمة لتحديد أولوية كل شخصية
(عالية / متوسطة / عادية — الافتراضي "عادية"). تظهر هذه الأولوية بلوحة
الإدارة كعمود ملوّن، وتُستخدم لمساعدة المنظمين على القرار عند نفاد الأماكن.

## رموز VIP

يولّد النظام رمزاً فريداً **عشوائياً** لكل شخصية بالصيغة `VIP-2026-73412`
(وليس متسلسلاً 0001، 0002...) حتى لا يكشف الرمز نفسه ترتيب أو أولوية
التسجيل. يتحقق الخادم من عدم تكرار الرمز مع الرموز الموجودة فعلاً قبل
اعتماده، مع قفل (Lock) على مستوى الخادم لمنع أي تعارض عند الإدخال
المتزامن من أكثر من عضو.

## الخصوصية والأمان

- لا تُستخدم أعداد الأصوات في أي مكان — قائمة الأعضاء (`assets/members.js`)
  تحوي الاسم والمنصب فقط.
- صفحة `verify.html` العامة تعرض الاسم/مكان العمل/المنصب فقط، ولا تعرض رقم
  الهاتف أو البريد أو اسم عضو النقابة الذي أضاف الشخصية.
- كل عمليات لوحة الإدارة (`adminList`, `adminUpdateStatus`, `adminUpdateVip`,
  `adminDeleteVip`) تتطلب كلمة المرور، والتحقق يتم في Apps Script وليس في
  المتصفح.
- لا يوجد أي مفتاح API أو Token أو كلمة مرور داخل الكود أو هذا المستودع.
- الصفحتان الرئيسية والإدارية غير مفهرستين (`robots.txt`) ويجب عدم مشاركة
  روابطهما إلا مع الأعضاء المخوّلين.

## QR Code

يُنشأ رمز QR لكل شخصية عبر خدمة عامة مجانية بدون مفتاح
(`api.qrserver.com`) يشفّر رابط التحقق `verify.html?id=VIP-2026-0001` فقط —
لا بيانات حساسة داخل الرمز.
